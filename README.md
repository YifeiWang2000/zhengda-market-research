# zhengda-market-research ｜ 正大杯市调全流程教练

面向「正大杯」全国大学生市场调查与分析大赛参赛团队的 AI 指导技能，覆盖选指导老师、选题、调查设计、调查实施、数据分析、报告、PPT、展示视频、答辩与提交。

采用**分阶段指导、成果审核、项目续接**的工作方式：从团队当前进度进入，每轮推进到可审阅成果，指出问题、给出修改办法，并记录下一步。目标是帮助团队完成有证据支撑、能够复核、能够在答辩中解释的研究。

默认使用中文，默认第十七届、本科组；可按团队实际情况切换届次与组别。**不提供知识赛备考、题库或模拟考试。**

## 主要特性

- **覆盖实践赛全流程**：从规则核查、导师选择和团队分工，到问卷、访谈、分析、报告及展示材料，按当前阶段提供具体成果。
- **先核实截止时间**：优先核查校内报名、选拔与材料截止，按最早适用节点倒排计划，预留导师审核、修订和提交时间。
- **选题先审研究价值**：优先聚焦市、省范围内可调查的实际行业与社区问题，核验文献、官方政策和可达资源，再形成导师讨论材料与定题记录。本科组不意味着只研究大学生或校园。
- **研究问题驱动分析**：先判断变量、调查执行与方法适配，再选择模型；结果不显著时检查问卷、数据处理、样本信息与分析方法，不靠筛数据追求显著。
- **报告优先、展示随后**：默认交付可编辑 Word 报告，经过篇幅与内容验收，并由用户明确确认该版本无误后，再制作 PPT 及逐页讲稿。
- **审核意见可落实**：每条主要问题说明位置、影响、具体改法与复核方式；已有成果先审核再局部修改。
- **跨会话继续项目**：在团队自己的 `zhengda-project/` 中保存进度、决策、规则、证据与审核记录，下一次从已有状态续接。
- **案例参考与团队数据分开**：保留案例学习笔记、索引与阅读覆盖记录，不随技能分发原始报告、PPT 或视频。没有原作资料库也能使用主要指导流程。

## 三项硬性门槛

以下是本 Skill 的工作与交付标准，**不等同于官方比赛规则**。适用赛事要求须另行核查；存在差异时应明确记录并处理。

| 门槛 | 具体要求 |
| --- | --- |
| 研究价值 | 正式定题前，识别尚未解决且影响具体决策的问题，并用可核验证据说明相对既有知识的增量。未通过或待核验时，不正式定题、不锁定正式问卷、不生成完整报告。 |
| 报告篇幅 | 完整报告同时满足正文 **45–55 页**、全册 **60–80 页**，按实际排版或渲染页数验收；合成数据演示和技能测试也适用。未达标不称完整报告、定稿或报告阶段通过。 |
| 展示启动 | 先交付符合验收条件的报告；只有用户明确确认该版本报告无误，才能生成 PPT 及配套逐页讲稿。“继续”或“全流程完成”不等于报告确认。 |

选题按以下顺序推进：

```text
方向储备 → 市/省内聚焦 → 研究价值预审 → 可行性筛选
         → 中国官方政策核验 → 导师讨论 → 团队定稿
```

研究价值待核验、缺少政策原文或尚未完成真实导师讨论时，选题保留待定状态。用户选中一个方向，只代表候选偏好。

## 阶段与交付

| 当前阶段 | 主要交付 |
| --- | --- |
| 规则、组队与时间安排 | 适用规则清单、里程碑、信息缺口 |
| 选择指导老师 | 候选导师比较、沟通提纲、团队分工建议 |
| 选题、文献与研究问题 | 候选题、研究价值预审、官方政策依据、导师讨论材料、定题记录 |
| 抽样、问卷、访谈与预调查 | 调研方案、问卷与访谈工具、试测修改记录 |
| 调查实施、清洗与统计分析 | 可追溯数据、分析脚本或操作记录、结果与解释边界 |
| 报告、图表与附录 | 可编辑 Word 报告、图表与附录、审核及修订意见 |
| PPT、展示视频与答辩 | 报告确认后的 PPT 与讲稿、按需要制作的视频、模拟问答与复审 |
| 提交与复盘 | 提交核对表、成果同步检查、可复用经验 |

每轮默认给出：**本轮目标、具体成果、审核结论、团队待落实动作**。审核结论分为「通过」「修改后通过」「需重做或补证据」。缺少官方评分表时使用维度诊断，不编造官方权重或得分。

## 安装

本仓库根目录就是完整技能目录，`SKILL.md` 位于根目录。安装时保留 `references/`、`agents/` 和 `scripts/`，不要只下载 `SKILL.md`。

### 安装前准备

- 本仓库为私有仓库，安装者须使用有访问权限的 GitHub 账号；团队成员需先获得仓库访问权限。
- 命令行安装需要 Git，并已配置 GitHub HTTPS 身份验证。浏览器或 ChatGPT 中登录 GitHub，不等于本机 Git 已登录。
- 如使用 GitHub CLI，可先运行 `gh auth login`，选择 GitHub.com、HTTPS 并按提示登录，再运行 `gh auth setup-git`；已有可用 Git 凭据时无需重复设置。

### Windows（PowerShell）

```powershell
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.agents\skills" | Out-Null
git clone https://github.com/YifeiWang2000/zhengda-market-research.git "$env:USERPROFILE\.agents\skills\zhengda-market-research"
```

### macOS / Linux（终端）

```bash
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/YifeiWang2000/zhengda-market-research.git "$HOME/.agents/skills/zhengda-market-research"
```

上述命令采用 [Codex 官方文档](https://developers.openai.com/codex/skills/)列出的用户级技能目录 `~/.agents/skills/`。如果已经在其他被当前客户端识别的目录（例如 `~/.codex/skills/`）安装了本技能，请更新原有副本，避免重复安装同名技能。

### 不使用命令行

1. 使用有权限的账号打开[本仓库](https://github.com/YifeiWang2000/zhengda-market-research)，点击 **Code → Download ZIP**。
2. 解压后，将包含 `SKILL.md` 的文件夹重命名为 `zhengda-market-research`。
3. 将整个文件夹放入下列位置；目录不存在时先创建：

| 系统 | 技能目录 |
| --- | --- |
| Windows | `%USERPROFILE%\.agents\skills\zhengda-market-research\` |
| macOS / Linux | `~/.agents/skills/zhengda-market-research/` |

确保 `SKILL.md` 直接位于上述技能目录中，不要多套一层 `zhengda-market-research-main` 文件夹。

Codex 会自动检测技能变化；若技能未出现，重启 Codex。随后在技能选择器中找到 `zhengda-market-research`，或发送：

## 使用

直接点选该技能，或在对话中明确指定名称，并提供已有材料。可以从任意阶段进入，不必从头重做。

### 从零开始

```text
请使用 zhengda-market-research 指导我们参加正大杯。
我们参加第十七届本科组，目前还没有确定选题。
学校与赛区：……
成员能力与每周可投入时间：……
能够接触的企业、社区或受访人群：……
最近的校内截止日期：……
请先判断当前缺口，再推进到第一份可审阅成果。
```

### 已有候选题或问卷

```text
请使用 zhengda-market-research 审核附件。
先检查选题的研究价值、调查可行性以及问卷与研究问题是否对应，
列出主要问题的位置、影响、具体改法和复核方式。
```

### 已有数据或报告

```text
请使用 zhengda-market-research 检查现有数据和报告。
先审核数据处理、方法适配及结论证据，再对需要修改的部分做局部修订。
请保留可复现记录，并列出需要同步修改的摘要、图表和展示材料。
```

### 续接与启动展示

```text
请读取当前项目目录中的 zhengda-project，接着上次的审核记录推进。
```

符合验收条件的报告经检查无误后，可明确指定版本：

```text

请以该版本为依据，制作 PPT 和配套逐页讲稿。
```

## 工具与交付格式

- **报告**：默认可编辑 `.docx`，不常规导出 PDF；真实赛规要求其他格式时，单独记录并安排。
- **分析**：沿用团队的 Excel、SPSS、R 或 Python 选择，保留实际运行的脚本或可复现操作记录。
- **PPT**：报告确认后制作可编辑 `.pptx`，检查页面并与报告数值对账。
- **视频**：按赛段要求与现有工具能力制作，核查音画、字幕、时长和格式。

本技能提供工作流程与制作要求，**不内置全部文件生产工具链**。缺少特定插件时仍可进行文本指导，并明确剩余制作步骤；未生成或未验证的文件不会被称为已完成成品。

## 数据真实性与使用边界

- 原始调查、访谈、专家意见、文献、政策与企业信息须有来源，不把案例中的结论移植成新团队的事实。
- 没有真实数据时，可先交付调研方案和分析脚本。团队明确要求时，可生成标识清楚的合成数据用于试跑、演示或披露的模拟研究。
- AI 问卷试测须注明「AI 模拟，非真人试测」，不能计入真实样本，也不能据此确认真人理解或正式调查通过。
- 团队明确同意采用模拟数据后，可继续清洗、建模、制图与解释；须记录同意范围与数据版本，模拟结果不能证明真实市场结论。
- 不以模型数量、统计显著或信效度数值代替研究价值，也不承诺获奖。
- 联系导师或受访者、发送问卷、上传或提交材料，需要对应的用户授权。

## 案例与来源说明

本技能包含通用研究方法、规则快照以及案例学习笔记。规则快照用于定位核查线索，具体届次、组别、赛区及校内要求仍须以适用通知为准。

原始案例报告、PPT 和视频不随技能分发。需要回查原作时，由团队提供有权使用的外部资料目录；没有原作也能继续通用指导。已建索引、已提取文字与已阅读是不同状态，实际覆盖范围见 `references/coverage.md`。
