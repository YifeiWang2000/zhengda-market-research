# 文件制作工具选择

由代理主动给出适合团队的默认方案、用途与交付格式，不只反问“你用什么软件”。先检查当前环境可用能力，读取适用工具Skill；不能因案例视觉风格推断作者实际用了什么软件。这里是复现类似成果的建议，不是原作者软件使用事实。尊重团队已有工具与用户指定Word交付，不默认安装付费软件、购买服务或上传资料。

| 成果与案例目标 | 默认可选工具 | 实际交付与检查 |
|---|---|---|
| Word报告，参考文创的简洁底版与宝妈的主题一致性 | 当前可用Word文档能力；可用python-docx等生成DOCX，Word/WPS人工协作 | .docx，标题样式、目录、页眉页脚、表格、分页及打开/渲染检查，不要求PDF |
| 数据清洗与分析 | Python/R作可复现分析，Excel作数据核对；团队熟悉且环境可用时用SPSS | 数据、脚本或软件操作记录、实际结果；不伪称执行不存在的软件 |
| 图表，参考统一的绿/蓝/橙主题 | Python绘图库、R绘图或Excel原生图表 | 配色语义一致的图和可修改记录，数值直接来自分析，非AI想象图表 |
| 问卷和访谈工具 | Word稿及可导入文本；团队选定的平台实施 | 分支、编码、版本可核查；平台发布/发送另按用户授权 |
| 流程图、框架图 | 可用的draw.io或PowerPoint形状 | 可编辑源文件及插图，结构与研究一致 |
| 封面和方案示意，参考食品插画/主题海报 | Word/PowerPoint排版，必要时可用图像生成能力制作装饰素材 | 清晰可编辑标题与封面；示意图不得冒充产品测试、真实受访者或实地活动 |
| PPT（仅用户确认报告无误后启动） | 当前演示制作能力或PowerPoint | 可编辑.pptx与讲稿，实际页面检查及报告数值对账 |
| 视频，赛段要求时 | 可用视频编辑工具；团队可使用剪映等，环境支持时代理使用视频插件或FFmpeg | 实际素材、编辑记录/工程和成片，音画/字幕/时长/格式播放检查 |

第一次制作时交付简短“成果—所选工具—格式—为何适合—当前可用性”表。给一个默认方案即可，只有成本、兼容性或团队偏好有实质差异时提供备选。不强迫团队同时掌握所有工具。缺能力时给可继续加工的源材料与明确剩余动作，不把工具缺失作为已交成品。
