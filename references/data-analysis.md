# 调查实施、数据清洗与分析审核

## 执行与留痕

每次采集记录日期、地区/渠道、执行者、工具版本、接触/拒访/完成数量和偏离方案情况。线上线下来源可追踪；现场照片不能代替抽样记录。访谈转写和问卷数据按匿名ID管理，公开展示先去标识。保留只读原始数据，清洗和分析在副本进行。

## 清洗

先读问卷和变量字典，再检查编码、单位、缺失、跳题、多选展开、重复、逻辑冲突、异常时长、直线作答和异常值。质量阈值依据预调查与内容解释，单一规则不直接证明造假；每类剔除记录规则、数量、重叠和保留/排除理由。不得为显著性删样本、改回答或补出不存在的受访者。

输出数据版本、样本流转表、变量字典、清洗日志、可复现脚本或软件操作记录。总体/分组/每题有效样本数可以不同，标明分母；缺失不能默认补零。合并问卷、访谈与评论前检查单位和来源，不混用样本量。

## 分析选择

| 研究需要 | 可考虑的方法与先决条件 |
|---|---|
| 现状、渗透率、认知/购买漏斗 | 描述统计与区间；明确逐层条件分母与总体范围 |
| 群体差异与关联 | 交叉表、适合变量尺度的检验/模型；检查稀疏单元、设计与多重比较 |
| 测量潜在构念 | 量表来源、维度与适用性；信度/因子结构分别检查，KMO不是结构效度已证实 |
| 购买意愿/满意度关联因素 | 依据因变量选回归或潜变量模型；检查混杂、共线、拟合与可解释性 |
| 人群细分 | 按变量类型选择距离与聚类，检查稳定性与业务解释，不把预设画像当发现 |
| 预测 | 划分训练/验证、预处理只在训练内拟合；报告基线、泛化、泄漏与类不平衡 |
| 访谈/评论 | 采集范围、抽取方式、编码或主题规则、负例；文本频次与情感不等于全体消费者态度 |
| 产品/价格/渠道方案 | 偏好与可行性证据对应；没有实验不声称策略已提高实际销量 |

不要求每个项目使用所有方法。选择最少但足够回答问题的分析，再根据未解释的问题增加方法。重要统计结论报告估计量、区间、实际意义与样本基础；“p=0.000”是软件舍入，不能称概率为零。探索性分析与验证性分析分开，不能回填假设冒充预先设定。

横截面相关、SEM路径、特征重要性、贝叶斯网络方向和模拟优化结果均不自动构成因果证据；解释时说明设计所允许的范围。便利样本的结论不要外推到全国。信度高不证明随机抽样/真实作答，游程检验也不证明总体代表性。

对关键输出做内部一致性复核，例如回归系数与标准误、检验统计量和p值相容，Logistic的OR与exp(B)相容，分类指标分母来自真实测试集。发现矛盾先回查软件输出和编码，不凭报告文字替其圆场。不能因系数方向不符合预期删变量；购买经历、购买意愿和实际购买行为不是同一变量。

检查条件比例的方向：“购买者中女性多”不等于“女性更易购买”；预先筛选的目标群体不能靠样本构成再证明其最优。Logistic遇到零单元、巨大系数或标准误时检查完全/近完全分离、收敛与区间；聚类画像中的职业、家庭和心理属性必须来自测量或可定位访谈。

模型输入、输出、图表、摘要与建议逐项对应。没有原始数据时只能审核报告所展示的信息与论证，不能确认统计计算正确；保留复核所需数据清单。模型失败或结果不显著时按下节排查，不制造成功输出。

## 不显著结果的排查与回退

**触发条件：核心比较、关系或模型结果不显著时，必须开展问卷设计专项检查并留痕，不能直接用“零效应也有价值”跳过检查。** 这是一项必要诊断，不是预先认定问卷一定有问题。检查应与原始数据和样本信息核对相互印证，不单凭p值决定改题。

问卷专项检查至少覆盖：研究问题到题项的对应是否完整；受访者能否按预期理解题意；是否一题多义、诱导或使用陌生术语；选项是否遗漏、重叠或强迫表态；量尺是否有区分度和天花板/地板效应；适答与跳题是否丢失关键人群；时间窗口是否一致；所测变量是否只是代理而未触及核心问题。用题本、回答分布、原始记录及真实试测/访谈核查，缺少真人证据时标待核实，不编造理解测试。

同步检查稀疏组、样本覆盖、有效信息量、区间宽度、检验或模型适配，区分测量缺陷、样本不足、处理错误与可能的零效应。在reviews.md记录“问题位置—支持证据—对结论影响—修订或保留理由—复测/补采要求—复核结果”。仅有检查清单但未实际核查，不算完成。


按团队要求，先看问卷结果和处理是否有问题：原始记录、纳入对象、有效分母、缺失/跳题、多选与反向编码、异常作答、类别稀疏、量表理解、天花板/地板效应、样本覆盖及模型适用性。发现错误先有据修正或补采，保留日志并复跑，不凭结果方向删除真实样本。

数据处理没有问题后，再检查问卷结构是否确实未测到研究问题：构念定义、题项遗漏/重复、表述、量尺、分支及内容效度。只有识别到具体测量缺陷，才调整问卷结构，经试测后重新采集相应数据；保留旧版结果，说明探索性修改，不改写旧答案或假装新版从一开始就使用。不同版本不得直接无说明合并。

修订和复测后仍无法回答核心问题，可与团队和导师讨论缩小范围、调整研究问题或更换题目；同步重核政策依据、抽样/数据需求、时间和后续材料。零效应或不确定结果本身可以是有价值的发现：若测量和设计合理，不显著不自动要求改问卷或换题，更不能反复尝试直到显著。比较效应大小、区间和实际意义，检查样本信息是否足够，再决定保留发现、补采或调整。

## 团队要求生成数据时

允许按团队明确要求生成合成/模拟数据，供团队采纳用于分析试跑、问卷结构演示、方法教学或明确披露的模拟研究。生成前明确用途、变量、取值约束、样本规模和假设；不能声称模拟数据来自真实受访者。

合成数据单独命名和保存，说明文件及数据标识注明“合成数据，非真实调查”；程序生成时附生成逻辑、随机种子和代码，语言模型直接生成的试测回复按[AI模拟试测](research-design.md#ai模拟试测)保留假设、提示说明、题本版本与完整输出；产生的图表与结论同样注明来源。禁止混入真实回收数据冒充受访者，不能补造问卷、访谈、回收率或执行记录，也不能为了满足显著性、信效度阈值生成再包装为真实研究结果。

团队可选择采用模拟方案或演示成果，但不能据此将“正式调查完成”或“真实实证作品完成”标通过。能否把披露的模拟研究作为参赛成果，须另外核实当前赛规；未核实不能承诺可提交。报告中的真实证据、模拟输出和待验证假设分别标识。

## 团队同意采用模拟数据进行后续分析

团队可以明确同意将AI模拟数据作为后续分析的输入，按处理真实调查数据时相同的规范执行清洗、编码、描述统计、适配的模型、图表、结果解释及分析报告。该同意授权完整的模拟分析流程，不改变数据来源；不得删除来源标识、将模拟样本计为真实受访者，或虚构问卷发放、回收率、访谈和现场执行记录。

- 在project-state.md记录团队授权原话、日期、采用的数据版本及用途；已有明确同意不重复询问。团队已直接要求采用模拟数据继续分析时，简短说明将保留模拟标识后执行；仅生成过模拟数据但未授权后续使用时，先取得同意。
- 对“当真实数据分析”“按正式调查流程处理”等要求，明确采用的是同样的分析步骤与质量检查，输出仍标“AI模拟数据分析，非真实调查”。若要求对外冒充真实数据，不执行伪装，可继续提供来源透明的分析成果。
- 按问卷结构及研究问题实际运行适用分析，交付清洗记录、可复现操作、结果表图及解释；不得仅因数据为模拟而停在建议阶段，也不为凑模型或显著性修改生成结果。
- 统计结果只能描述该模拟样本及其生成假设；显著性、信效度、拟合度不能证明真实人群的规律或验证生成器预设的市场关系。分开记录计算与流程检查通过、真实证据待补。
- 分析报告可以明确披露模拟来源；称为“完整报告”仍须满足既有研究价值与篇幅门槛，PPT仍须等待用户确认对应报告。采用模拟数据的同意不等于这些门槛自动通过，也不自动授权对外提交。

## 研究价值复核

分析结束必须回到研究价值证据卡，对照已知基线说明新增证据与决策影响。只有公认共识、未经测量的画像或合成机制预设关系时，研究价值不得通过。显著性不保证价值，不显著也不自动否定价值；后者先完成上节问卷与数据专项检查，再根据估计大小、区间和实际决策判断能否形成有用证据。

## 审核交付

交付能运行的分析记录、关键表图与解释、稳健性/敏感性检查（仅做有必要的）、适用边界、结论—证据对应表。复核聚焦分母、样本流程、编码方向、模型假设、夸大因果与决策可行性，不把排版精美视作分析通过。
