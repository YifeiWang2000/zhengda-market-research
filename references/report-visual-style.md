# 封面与正文视觉风格

本文件来自对部分往届报告实图的观察及设计建议，不是获奖因果、官方审美要求或全库频率统计。默认封面突出主题，正文便于连续阅读，图表与封面共享主色；团队已有风格时先评估再局部改进。匿名和封面模板要求优先，案例出现的学校、团队、企业标识不构成允许使用的依据。

## 封面

可采用主题海报型或简洁研究报告型，不规定统一风格。用一个主要视觉主体解释对象或场景；标题最多分为便于记忆的短标题和交代地区/对象/问题的完整研究题目，后者必须清楚可读。控制字体种类、图片数量和装饰密度。照片、插画、几何图形应协调；不把营销口号或产品图当实证结论。

## 正文与图表

优先白底或极浅底、黑灰正文，主题色集中在章节、页眉、图表与少量重点。可用一个主色、一个辅助色和一个强调色起步，类别较多时按需要扩展；不是所有项目只允许三色。抽查连续页面的阅读负担，不只评单页美观。

| 数据关系 | 配色与编码 |
|---|---|
| 同一指标比较多个地区/产品 | 同一主色，必要时突出重点对象 |
| 有序程度或数值 | 同色由浅到深，程度与深浅单调对应 |
| 支持—中立—反对 | 两端区分、中间中性色，全文顺序一致 |
| 无序客群或品牌 | 易区分的类别色，固定颜色对应，不暗示不存在的高低 |
| 表格和回归结果 | 黑灰文字、少量底色，突出有意义的信息而非满表上色 |

颜色承载数据含义：同一客群/变量跨图保持同色、同顺序；图例、正文与编码一致。用文字、标记或线型辅助识别，不只依赖红绿差别；浅色背景搭配深色文字，深色块中标签保证对比度。同色系过于相近时减少类别、换编码或直接标注。

常规统计图优先二维，减少阴影、厚边框、立体与爆炸饼图；雷达图仅在维度可比较且确有用途时使用。统一字体、字号、线宽、图题、单位和百分比精度；不同软件导出图也应协调，但不得为风格改动结果。表格表头/分组可用浅底，网格适度，不逐行随意上色。

制作后以最终Word文档实际阅读尺寸（打开或渲染预览）抽查封面、文字密集页、图表密集页、模型图和表格：标题完整、标签不截断、图例可辨、色阶有序、重点不过量；必要时检查灰度显示。图表还须通过报告的证据与数值审核，美观不替代正确性。
