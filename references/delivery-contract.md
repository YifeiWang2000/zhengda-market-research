# 阶段交付与完成条件

依据部分已审读报告、问卷、PPT及视频画面的做法与团队协作需要制定，不是官方评分标准，也不表示已完成全流程实测。与各阶段专业指导共同使用。允许阶段并行、合并或回退，但PPT必须等待用户确认报告无误，不为形式重复已完成成果；涉及真实数据和反馈的状态不得用生成内容替代。

## 零基础团队第一轮

目标是明确能否推进、先做什么、谁负责、何时交。只追问影响下一步的信息，已有答案不重复问；不要求第一次就定题。

| 交付 | 必含内容 |
|---|---|
| 项目启动卡 | 届次、组别、学校、人数、成员能力与可投入时间、预算、可达对象与资源；未知项明确标注 |
| 资格与期限核查表 | 校内报名、选拔、交稿、推荐与全国相关节点；来源、核实状态、负责人、下一步 |
| 分工与导师准备单 | 研究、调查、分析、报告、展示的主责及复核人；导师标准、已有候选或查找渠道、沟通简报 |
| 选题资源盘点 | 可进入场景、可接触人群、观察到的问题；主动给出3–5个具体候选题让团队选择；未指定校园范围时至少覆盖3类人群/经营主体及2类校外场景，校园题最多1个，列渠道、政策待核项与最大困难；缺地区用明确占位符 |
| 近期行动表 | 原则上未来7天，按实际期限调整；任务、负责人、时间、交付物与依赖 |

以上可合并为一个可修改启动文件。第一轮完成须每个关键未知项有核实动作与负责人，团队清楚下轮带回什么（校内通知、成员时间、导师回复、渠道确认等）。临近或已过报名节点优先处理资格；学校或期限未知仍可盘点资源和分工，但不能标资格已确认。第一轮交付完成不等于报名、导师接受或定题完成。

## 全阶段验收

| 阶段 | 交付 | 完成条件 |
|---|---|---|
| 资格与启动 | 启动卡、规则/期限表、近期行动 | 适用资格和关键期限已核实；未知项有影响与下一步；报名成功以真实登记/回执为准 |
| 组队与导师 | 分工、候选比较、沟通简报、合作记录 | 成员确认职责和时间；导师真实接受；适用名额和登记已核实，未回复不算接受 |
| 选题与立项 | 候选比较、研究价值证据卡、定题卡、官方政策证据、导师讨论、工作题目 | 正式定题前已完成研究价值预审且状态为通过（待核验或未通过不得正式定题、锁定正式问卷或生成完整报告），问题与边界明确、渠道可行、政策相关且已核实、导师意见已处理、团队确认 |
| 文献与研究框架 | 文献证据表、概念定义、研究问题树、变量/证据映射 | 说明已有研究与本题缺口，概念可测量，各问题有拟获取证据，引用可追溯 |
| 调查方案与工具初稿 | 抽样、样本量依据、问卷、分角色访谈提纲、分析计划 | 对象可达，实际执行与抽样名称一致，每题有用途，筛选/跳题/选项/时间窗/量尺检查通过，可试测 |
| 预调查与定稿 | 真实试测、问题与修改对照、正式问卷、变量字典；团队要求AI提供回复时先交付独立标识的模拟试测包 | AI模拟可完成逻辑检查、修订与模拟复测，记“AI模拟试测完成；真人试测待开展”；正式定稿仍须真实试测解决关键理解及跳转问题，重要测量修改经必要复测，工具/编码/计划一致，团队确认版本 |
| 正式调查 | 原始问卷数据、访谈、渠道与执行日志、样本进度及偏离说明 | 达到研究所需覆盖和有效信息要求；不足则补采或调整范围并记录，不能只按份数通过；资料可追溯 |
| 清洗 | 原始保留版、清洗数据、字典、日志、样本流转表 | 数量能对账，缺失/跳题/多选/反向编码正确，剔除有依据，处理可复现，未改造原始回答 |
| 分析与发现 | 分析记录、关键图表、解释、结论—证据表 | 新增证据与决策贡献经研究价值复核；核心问题回答或明确证据不足（证据不足不标研究价值通过）；不显著必须检查问卷设计并核查数据、样本与方法，再按确有测量缺陷修订问卷并重采，仍不可回答才讨论改题；方法适配，关键结果已复核，关联/预测/因果分清，团队能解释 |
| 建议与方案 | 对象、依据、行动、资源、优先级、验证办法的方案卡 | 建议回指发现，执行者明确，考虑成本约束，设想/测试/实际实施分开 |
| 报告与视觉 | 可编辑Word报告（.docx）、必要附录、参考文献、最终图表 | 研究价值与证据验收通过，主线连贯、数值引用一致、无待填占位，正文45–55页且全册60–80页实际页数验收通过（计数与有据例外按报告与交付），符合匿名，目录图表分页可读，实际DOCX打开或渲染检查完成；不要求导出PDF |
| PPT与讲稿 | 用户明确确认的报告版本对应的可编辑PPT、逐页讲稿、必要备用页、分工与排练记录 | 启动前已有用户确认报告无误的记录；发现突出、与报告一致，实际排练符合时长，图表清楚，转场及成员交接完成 |
| 视频（赛段要求时） | 录制安排、真实素材、剪辑版本、最终视频；按需保留字幕/工程 | 录制→剪辑→字幕核对→导出→成品播放检查完成；音画、时长、格式、匿名符合要求；无要求不强制作视频 |
| 答辩 | 针对性问题、真实回答、追问整改记录、证据索引 | 完整模拟已做，关键方法与发现有人能解释，重点质疑有证据或诚实边界，遗留问题处理或记录 |
| 提交 | 本赛段清单、最终包、检查结果、实际回执 | 版本明确且文件可打开；资格/附件/命名/格式/匿名/期限逐项核对；成功以真实回执或系统状态为准 |

导师与初步选题可并行；调查中可写方法部分，结果和结论须等真实数据。遇到未通过条件，指出位置、影响、具体补件与复核方式，继续不受影响的准备工作，不假装通过或将整个项目无条件冻结。

## 成品交付

区分团队内部保留包与赛段提交包，内部材料不自动全部上传。

| 成果 | 内部保留 | 对外提交 |
|---|---|---|
| 调查工具 | 正式问卷、提纲、字典、版本修改记录 | 按规则进附录或附件 |
| 数据分析 | 原始/清洗数据、日志、脚本或可复现软件记录、关键输出 | 仅规则要求且适合公开的部分 |
| 报告 | 可编辑Word（.docx）、参考文献、必要附录 | 默认Word，不将PDF作为常规交付或验收条件 |
| 图表视觉 | 可编辑图表或生成记录、正式导出图、配色/样式约定 | 随报告/展示提交 |
| 展示 | 可编辑PPT、讲稿、备用页、排练记录 | 按赛段要求 |
| 视频 | 实际素材、可修改工程或明确制作记录、最终成片 | 赛段要求时提交 |
| 答辩 | 问答记录、证据定位、成员分工 | 通常内部使用，按实际规则处理 |
| 提交记录 | 版本清单、核对结果、时间、回执 | 按实际系统办理 |

报告采用用户明确选择的Word交付，不再默认提供LaTeX源文件或PDF；其他分析、展示、视频软件可按团队和环境选择。如已核实赛规另需PDF等格式，明确标注“用户交付格式与参赛格式的差异及待办”，不能把Word称为已满足该项提交条件，也不能未经用户要求把PDF恢复为常规交付。

交付状态：草稿（可审阅，待补）、待核实（依赖真实数据/导师/赛规）、通过（必要内容与检查已完成）、需修改（问题/负责人/复核条件明确）。“修改后通过”必须在修改复核后才标通过。仅有大纲、文字稿或脚本不算DOCX、PPT或视频成品；缺工具时说明实际交付、未完成转换/检查与接续方式，不伪称文件已生成。

采用规则核查中的提前量：报名准备建议提前3–7天；完整报告在校内交稿前7–14天供导师审核；提交争取提前1–2天并查回执。均可按真实期限调整，不是官方规定。最终修改后同步核验报告、PPT、讲稿和视频数字版本。
